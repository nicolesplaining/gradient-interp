This numerical test cannot establish component interpretability. SVD used about 500 active fitting coefficients per example, compared with roughly 8 for atoms. Better reconstruction alone is expected from a dense low-rank representation and is not the target scientific contribution.

Limits that matter

This is an architecture reconstruction because the original rank8 checkpoint was unavailable. The steering study reused public prompts and adapters. An execution amendment moved complete behavior families to a third supplied GPU; each within-family method comparison shares hardware, but seed42 baseline-relative quality comparisons include an A100/H100 difference. Content checks are narrow and output-length changes remain confounds. All strengths, negative findings, archived source, fixed examples and uncertainty are retained.
