Autoregressive tangent development results

This completed experiment tests numerical forecasts from atom reconstructions. It does not test whether the atoms have valid behavioral descriptions or selective causal effects. The separately running atom-centered study addresses those questions. Full gradients and SVD measure approximation loss; outperforming them is not a success requirement for atoms.

What was predicted

At every newly sampled prefix, the original model's final logits and their directional derivative produce a first-order approximation to logits after a batch update. Responses are sampled from that approximation at temperature 0.8, without applying the update. All forecasts were locked before any actual update. The test uses reconstructed Gemma-3 4B rank-8 query/value adapters, all 136 LoRA tensors, four old synthetic catalog-copying batches and four old questions. Rates are .0003, .003 and .03. Dictionary predictions reconstruct the batch gradient from sparse atom coefficients while restoring its projected magnitude. Full gradients, EKFAC projection, SVD16 and no change are retained.

Each seed has 32 independent forecast-stream samples per question and condition, and 128 independent evaluation-stream samples after the actual update. Each stream uses common randomness across conditions. Evaluation uses the same custom float32 uncached math-SDPA sampler as forecasting. The cap is 96 tokens. There is one batch per style and only two evaluation questions. The adapters, task families and questions were previously inspected. These are development results, not untouched-data confirmation.

Atom forecast errors

Relative RMSE compares forecast error with predicting no change: one is equal error; below one is lower error. Probability changes and their absolute errors below are fractions; multiply by 100 for percentage points. Token errors are in tokens. The table includes every rate and endpoint, both same-question prediction and transfer of the mean calibration-question forecast to each evaluation question. Same-question access is not template transfer. No estimates are clipped.

The atom reconstruction shows a limited numerical signal, with substantial failures. At rate .003, same-question copying nRMSE is 1.000 / 0.247 for seeds 42 / 43. The favorable seed-43 point estimate has absolute error 0.96 percentage points, but its paired bootstrap MSE-difference interval spans zero. Transferring the mean calibration prediction gives zero copying change at this rate in both seeds. At .03, same-question copying nRMSE is 0.958 / 1.180. Thus this run does not establish reliable copying forecasts across seeds or templates.

Large-step length forecasts do reduce error against no change: nRMSE 0.935 / 0.414 on the same questions and 0.897 / 0.747 after calibration-template transfer. Their pointwise MC-plus-question intervals are below one, but the size of the change is still underestimated. The same-question mean predictions are +1.24 / +3.12 tokens versus actual +16.93 / +5.49. This is a descriptive length result on four fixed development batches, not validation of atom meanings or a promoted primary success.

Numbered formatting remains a failure for the dictionary: no numbered responses appear in its evaluation-question forecasts, while actual large updates produce them. It also misses most severe truncation in seed 42. For the fixed plain-short batch at .03, actual copying falls from 97.27% to 31.64%, and 80.86% of responses truncate. The dictionary stream goes from 98.44% to 95.31% copying and predicts 1.56% truncation. Those are separate-stream baselines. The fixed first example preserves correct copying in the forecast while the actual response repeats and reorders tags until the cap. Uncertainty and limits

There are 1,000 descriptive paired bootstrap replicates. Forecast response indices and evaluation response indices are sampled independently within question, with each set shared across conditions. Additional question resampling draws two questions within each template; calibration questions and evaluation questions are sampled separately. The four fixed batches are not resampled because each style has only one batch. The CSV and bootstrap arrays separate forecast Monte Carlo variation, evaluation Monte Carlo variation, both streams, and both streams plus questions. These are pointwise intervals, with no multiplicity correction or two-seed population claim. A zero observed effect makes relative error undefined. If any replicate has an undefined relative error, its interval is withheld and the number of defined replicates is reported; absolute RMSE and MSE difference remain available. An empirical bootstrap cannot recover events absent from the saved samples. Thirty-two forecast responses make small effects coarsely resolved; identical paired samples can yield a degenerate interval without proving that the true effect is zero. There is no claim of success from selecting a favorable endpoint or seed.

Computation and audit

This surrogate is computationally expensive. The forecast total includes four representations at each batch/rate; the no-change method aliases a shared baseline. Evaluation runs one actual update per batch/rate with four times as many samples per question. A raw total-time ratio is therefore not an equal-work speed comparison. No efficiency or compression claim is made. Prefixes use full uncached forwards and JVPs. Recorded forward counts include the primal forward inside a JVP; JVP counts identify those calls rather than an additional independent primal forward.
