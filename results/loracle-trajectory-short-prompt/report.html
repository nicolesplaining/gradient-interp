A shorter LoRAcle question

How does this update change response formatting?

We asked one shorter question on exactly the same saved weight differences: "How does this update change response formatting?" There was no JSON requirement, list of possible answers, or instruction to infer more versus less. The model and decoding settings stayed the same.

The shorter wording changed the stories, but neither encoding clearly identified the actual switch from numbered lists to bullets in the second interval. The primary answer described returning JSON, lists or plain text without additional explanation. The upstream-compatible answer described single-line outputs with numbers separated by spaces. Those are not the measured change.

For the first interval, both encodings described producing sorted numbers rather than adding numbering to the same word labels. For the cumulative difference, the answers discussed JSON, reversed order, conditional formats or space-separated lists. The actual final model used bullets on all 24 evaluation prompts and preserved label order.

The zero-update control claimed the model learned numbered sections and bullet-pointed subpoints. This is an unsupported account of a change from a zero input. Zero tokens are unusual inputs for the interpreter; this demonstrates poor abstention here rather than proving that it ignores every real weight difference.

The small test does not measure chance performance or establish a general failure of LoRAcles. The answers used greedy decoding, so they were not random samples from the model. A different trajectory, checkpoint or question could behave differently. Measuring reliability would require independently trained trajectories and fixed questions evaluated without choosing the best answer afterward. This check only shows that simplifying this particular question did not recover the known format switch.

Same Qwen3-14B trajectory, saved weight differences, interpreter, token layout, greedy decoding and 192-token cap as the original toy. This changes the question only. Both previously reported encodings and all controls are retained. There is no new training or independent replication.

The question was chosen after seeing the original results, so this is a retrospective prompt-sensitivity check. Greedy decoding means these are not random response samples. This check cannot estimate performance across training seeds or the probability of chance agreement.
